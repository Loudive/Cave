# DECISIONS.md — журнал решений проекта

> Правило из гайда: через месяц файл спасёт от повторных споров с самим собой.
> Формат: дата · решение · почему · альтернативы, которые отвергли.

## 2026-10-27 · Шаг 0: каркас

- **Движок: Phaser 3 (не Kaplay, не Godot, не Unity).**
  Самый массовый HTML5-движок: Arcade Physics, частицы, Light2D, тайлмапы,
  тряска камеры из коробки, тысячи примеров. Модель GLM обучена на нём лучше
  всего. Kaplay оставлен как запасной вариант для прототипов, Godot отвергнут:
  бинарные сцены плохо вайбкодятся через чат.
- **Язык/сборка: TypeScript + Vite.** Типы спасают таблицы баланса; мгновенный
  dev-сервер; сборка в один клик для GitHub Pages.
- **base: `/Cave/`.** Игра живёт на project page GitHub Pages
  (loudive.github.io/Cave/). Локальный превью в песочнице собирается с
  `--base=/game/` (`npm run build:local`).
- **Публикация: GitHub Actions → GitHub Pages.** Автодеплой на каждый пуш в
  main. Правило гайда: каждое изменение заканчивается билдом и деплоем.
- **Пуши прямо в main, коммит после каждой рабочей версии** (правило гайда).
  Сообщения вида «step6: combat and eating».
- **Графика шага 0 — программные текстуры, не ассеты.** Гейм-фил важнее
  графики: светящийся прямоугольник в темноте уже передаёт атмосферу света.
  Пиксельные паки (0x72 DungeonTileset II) подключаются с шага 2+.
- **Палитра зафиксирована:** полотно #0B0B10, камень #1A1A26/#2A2A3A,
  биолюм-циан #58E6C8, споры #B36BFF, кислота #A8E34F, кровь #E23A4E,
  текст/UI #E8E6E3. Эти hex-коды идут во все промпты генерации артов.
- **Все числа — в JSON** (с шага 3: movement.json, с шага 6: balance.json).
  Код не содержит магических констант баланса.
- **Один класс = один файл, один шаг = одна система** (правила вайбкодинга).

## 2026-10-27 · Урок шага 0: клавиатура и хрупкость игрового цикла

- **Баг:** `keyboard.addKeys('W,A,S,D')` создаёт объект с ключами `W/A/S/D`,
  а не `up/left/down/right`. Обращение к `wasd.up.isDown` бросало TypeError
  уже в первом кадре сцены Cave — и **необработанное исключение внутри
  `scene.update()` убивает весь игровой цикл Phaser** (RAF-цепочка рвётся,
  игра замирает без единой ошибки в консоли сцены). Симптом: чёрный экран
  после перехода между сценами.
- **Фикс:** `addKeys({ up: KeyCodes.W, left: KeyCodes.A, ... })`.
- **Профилактика:** в index.html живёт независимый RAF-ватчдог и
  `window.__ERRS__` (ловля error/unhandledrejection), а игра публикует
  `window.__GAME__` — это позволяет агенту (agent-browser) детектировать
  «заморозку» цикла и читать состояние сцен при автотестах.
- **События клавиатуры в тестах:** синтетические KeyboardEvent из
  playwright-инструментов приходят с `keyCode: 0` — Phaser их не матчит.
  Для автотестов диспатчим события вручную с корректным keyCode через eval.

## 2026-10-27 · Шаг 1: GDD v1.0

- **Решение:** design/GDD.md заполнен полностью (8 разделов, 3–5 абзацев +
  таблица в каждом) по главе 6 гайда. Скелет шага 0 заменён без сохранения
  TODO-пометок.
- **Почему:** GDD — «единый источник правды» для всех следующих шагов;
  агент и пользователь ссылаются на разделы («смотри §4 — редкости»)
  вместо повторных объяснений.
- **Отвергли:** отдельный файл на каждый раздел (BDD-стиль) — 10-минутная
  читаемость важнее; копирование текста гайда дословно — GDD должен быть
  рабочим документом, а не пересказом.
- **Ключевые фиксации:** единая шкала редкостей (Обычный → Легендарный) с
  Проклятием как отдельной категорией; Свечение и Размер нельзя качать
  напрямую (следствие поведения); боссы дропают только постоянные
  легендарные гены; до шага 12 мета хранится в localStorage.
- **Числа баланса — не здесь:** GDD содержит правила, не числа. Все числа
  переезжают в src/config/*.json с шага 3.

## 2026-10-27 · Шаг 2: скелет и загрузчик ассетов

- **Решение:** ассеты — настоящие PNG-файлы, генерируемые на этапе сборки
  скриптом `scripts/generate-assets.mjs` (чистый Node: zlib + свой PNG-энкодер,
  детерминированный seed). BootScene перешла на реальный загрузчик Phaser
  с событийным прогресс-баром; манифест — `src/config/assets.ts`.
- **Почему:** «фальшивый» прогресс на твинах ничего не проверял; теперь
  конвейер ассетов реален с первого дня (добавил файл + строку в манифест —
  ассет в игре), а генерация воспроизводима и не тянет зависимостей.
- **Отвергли:** качать 0x72 DungeonTileset II сейчас — itch.io требует
  скачивание через свою форму, скриптабельно только хрупко; держать
  программные canvas-текстуры — у загрузчика нет работы. Пак 0x72 — шаг 3–4.
- **vite: `publicDir: 'assets'`.** PNG копируются в корень dist; пути загрузки
  относительные (работают и на /Cave/, и на /game/, и в dev). JS-бандл
  остаётся в dist/assets/ — конфликта нет.
- **Урок:** синтетический pointerdown через eval не двигает Phaser-ввод —
  для мобильной проверки нужны реальные события CDP (agent-browser
  mouse down/up). Клавиатура — наоборот: KeyboardEvent с корректным keyCode.
