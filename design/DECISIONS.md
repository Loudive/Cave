# DECISIONS.md — журнал решений проекта

> Правило из гайда: через месяц файл спасёт от повторных споров с самим собой.
> Формат: дата · решение · почему · альтернативы, которые отвергли.

## 2026-10-27 · Шаг 0: каркас

- **Движок: Phaser 3 (не Kaplay, не Godot, не Unity).**
  Самый массовый HTML5-движок: Arcade Physics, частицы, Light2D, тайлмапы,
  тряска камеры из коробки, тысячи примеров. Модель GLM обучена на нём лучше
  всего. Kaplay оставлен как запасной вариант для прототипов, Godot отвергнут:
  бинарные сцены плохо вайбкодятся через чат.
- **Язык/сборка: TypeScript + Vite.** Типы спасают таблицы баланса; мгновенный
  dev-сервер; сборка в один клик для GitHub Pages.
- **base: `/Cave/`.** Игра живёт на project page GitHub Pages
  (loudive.github.io/Cave/). Локальный превью в песочнице собирается с
  `--base=/game/` (`npm run build:local`).
- **Публикация: GitHub Actions → GitHub Pages.** Автодеплой на каждый пуш в
  main. Правило гайда: каждое изменение заканчивается билдом и деплоем.
- **Пуши прямо в main, коммит после каждой рабочей версии** (правило гайда).
  Сообщения вида «step6: combat and eating».
- **Графика шага 0 — программные текстуры, не ассеты.** Гейм-фил важнее
  графики: светящийся прямоугольник в темноте уже передаёт атмосферу света.
  Пиксельные паки (0x72 DungeonTileset II) подключаются с шага 2+.
- **Палитра зафиксирована:** полотно #0B0B10, камень #1A1A26/#2A2A3A,
  биолюм-циан #58E6C8, споры #B36BFF, кислота #A8E34F, кровь #E23A4E,
  текст/UI #E8E6E3. Эти hex-коды идут во все промпты генерации артов.
- **Все числа — в JSON** (с шага 3: movement.json, с шага 6: balance.json).
  Код не содержит магических констант баланса.
- **Один класс = один файл, один шаг = одна система** (правила вайбкодинга).

## 2026-10-27 · Урок шага 0: клавиатура и хрупкость игрового цикла

- **Баг:** `keyboard.addKeys('W,A,S,D')` создаёт объект с ключами `W/A/S/D`,
  а не `up/left/down/right`. Обращение к `wasd.up.isDown` бросало TypeError
  уже в первом кадре сцены Cave — и **необработанное исключение внутри
  `scene.update()` убивает весь игровой цикл Phaser** (RAF-цепочка рвётся,
  игра замирает без единой ошибки в консоли сцены). Симптом: чёрный экран
  после перехода между сценами.
- **Фикс:** `addKeys({ up: KeyCodes.W, left: KeyCodes.A, ... })`.
- **Профилактика:** в index.html живёт независимый RAF-ватчдог и
  `window.__ERRS__` (ловля error/unhandledrejection), а игра публикует
  `window.__GAME__` — это позволяет агенту (agent-browser) детектировать
  «заморозку» цикла и читать состояние сцен при автотестах.
- **События клавиатуры в тестах:** синтетические KeyboardEvent из
  playwright-инструментов приходят с `keyCode: 0` — Phaser их не матчит.
  Для автотестов диспатчим события вручную с корректным keyCode через eval.

## 2026-10-27 · Шаг 2: скелет и загрузчик ассетов

- **Решение:** ассеты — настоящие PNG-файлы, генерируемые на этапе сборки
  скриптом `scripts/generate-assets.mjs` (чистый Node: zlib + свой PNG-энкодер,
  детерминированный seed). BootScene перешла на реальный загрузчик Phaser
  с событийным прогресс-баром; манифест — `src/config/assets.ts`.
- **Почему:** «фальшивый» прогресс на твинах ничего не проверял; теперь
  конвейер ассетов реален с первого дня (добавил файл + строку в манифест —
  ассет в игре), а генерация воспроизводима и не тянет зависимостей.
- **Отвергли:** качать 0x72 DungeonTileset II сейчас — itch.io требует
  скачивание через свою форму, скриптабельно только хрупко; держать
  программные canvas-текстуры — у загрузчика нет работы. Пак 0x72 — шаг 3–4.
- **vite: `publicDir: 'assets'`.** PNG копируются в корень dist; пути загрузки
  относительные (работают и на /Cave/, и на /game/, и в dev). JS-бандл
  остаётся в dist/assets/ — конфликта нет.
- **Урок:** синтетический pointerdown через eval не двигает Phaser-ввод —
  для мобильной проверки нужны реальные события CDP (agent-browser
  mouse down/up). Клавиатура — наоборот: KeyboardEvent с корректным keyCode.

## 2026-10-27 · Шаг 3: контроллер существа

- **Решение:** вся механика движения — в классе `src/entities/Creature.ts`
  (один класс = один файл), числа — в `src/config/movement.json` с `_doc`-полями
  вместо комментариев (JSON их не умеет). Сцена — полигон: пропасть с
  респавном, ступени, шахта двух стен для wall jump, вышка для планирования.
- **Почему:** контроллер — «душа игры» (гайд, шаг 3); его надо чувствовать до
  любого контента. Debug-оверлей (F3) показывает состояние, vx/vy и окна
  coyote/buffer — настраивать параметры по ощущениям, а не вслепую.
- **Ключевые параметры первого прохода:** jumpVelocity −680 (апекс ~165px —
  ступени по 140px достижимы; первые −520 давали 92px — не хватало),
  coyote 100мс, buffer 120мс, wallSlideMaxFall 90, glideFallSpeed 85.
- **Грабли Arcade Physics:**
  1. Тела не сталкиваются без явного `physics.add.collider` — существо
     падало сквозь платформы, пока не добавили статическую группу + коллайдер.
  2. Private-поле `state` конфликтует со свойством `Sprite.state` →
     переименовано в `stateName`.
  3. Jump cut должен применяться ОДИН раз при отпускании (флаг `jumpCutDone`);
     вариант «умножать каждый кадр» гасил прыжок мгновенно.
  4. Спавн внутри статического тела выталкивает тело вниз — точки входа
     проверять отдельно.
  5. Синтетические клавиши через `eval` работают (keyCode обязателен),
     синтетический pointerdown — нет; CDP-клавиши не фокусируются в iframe.
  6. Ссылка на несуществующий глобал `Phaser` внутри eval-инструментации
     убивает игровой цикл навсегда (Phaser в ESM-сборке не глобален).
  7. Headless-браузер троттлит rAF между CDP-командами — суб-кадровые
     замеры нестабильны, это артефакт среды, а не игры.

## 2026-10-27 · Шаг 4: процедурные пещеры

- **Решение:** связка cellular automata (каверны) + drunkard's walk (туннель
  вход→выход по построению + 10 коротких блужданий для петель). Seed строковый
  (`ABC123`), слой глубины = `seed#d`; карта 163×100 тайлов × 16 px = 800 м
  глубины. Биомы — глобальные полосы GDD §6 с шумовым дрожанием границ
  (value noise в духе FastNoiseLite). Три слоя тайлов: камень / земля-край /
  декор (мох, кристалл, кость). Грибы и гнёзда мобов — по правилам биома.
  Seed + слой хранятся в URL (`?seed=…&d=…`), мини-карта на M (RenderTexture).
- **Почему:** туннель по построению гарантирует доходимость до выхода (критерий
  «90% попыток» перевыполнен: reach 0.94–0.99 на 12 сидов, 100% прошли);
  чистый TS без Phaser в `src/gen/` — генератор тестируется в Node за секунды;
  недостижимые карманы запечатываются камнем, чтобы мини-карта не врала.
- **Отвергли:** rot.js (генераторы заточены под top-down роуглайки, нужен
  сайд-вью), готовый fastnoise-lite (нулевой профит против 40 строк value noise),
  перегенерацию сцены через scene.stop/start (restart с data проще).
- **Грабли:**
  1. CA с deathLimit=4 «сдувала» стены до 90% воздуха (спираль к воздуху) —
     классическое правило «>4 стена, <3 воздух» (birth 5 / death 3) держит ~55%.
  2. Доп. блуждания 16×220 дисков r=2 = ~45к вырезаний на карту в 16к клеток —
     вырезали почти всё; норма: 10×110 дисков r=1 (~5% карты).
  3. `make.tilemap` с data-массивом: `-1` = пусто, слои с коллизией —
     `setCollisionByExclusion([-1])`; коллайдер существа принимает массив слоёв.
  4. Биомы считаются ДО flood-fill — finalize всегда получает biomes
     (ранний выход из параноидальной ветки ломал бы декор).
  5. Границы биомов дрожат по СТОЛБЦАМ (шум от x), не по строкам — иначе
     полосы были бы идеально горизонтальны.


## 2026-10-27 · Шаг 5: свет и атмосфера

- **Решение:** световая маска вместо Light2D: RenderTexture на весь кадр
  (depth 14) заливается `#0B0B10` с alpha 0.96, источники «вырезают» дыры
  радиальной `light-hole.png` (blend ERASE): игрок r=250 с дыханием (±4.5%),
  грибы r=150 (пульс читается масштабом твины свечения), врата r=270 (маяк
  пути), гнёзда r=95. Параллакс — два tileSprite-силуэта (768×1280,
  factor 0.16/0.38), вигнетка ПОВЕРХ маски (край кадра темен даже в свете),
  силуэтная мошь (14 шт.) рендерится над тьмой почти чёрным и растворяется
  в свете игрока (fade 0.9–1.35 R). Все числа — в `src/config/light.json`.
- **Почему:** гайд разрешает «более дешёвый вариант — световые маски»; маска
  не требует нормалмап и Light2D-пайплайна, работает на Canvas-fallback, даёт
  полный контроль радиусов (свет = будущая характеристика существа, GDD §5).
  Мошь — прототип читаемости мобов: «подсознание замечает движение раньше,
  чем глаз понимает»; на шаге 7 тот же приём переиспользуют настоящие мобы.
- **Отвергли:** Phaser Light2D (нужны нормалмапы тайлов, тяжелее на мобилках,
  на Canvas не работает вовсе), PostFX-пайплайны (WebGL-only, дороже).
- **Грабли:**
  1. `erase(texture-ключ)` рисует от верхнего левого угла — надёжнее держать
     пул Image с origin 0.5 и `setDisplaySize(r*2, r*2)`, тогда дыра центрируется.
  2. Вне экрана дыры не вырезаем (culling по камере ±r) — до 38 источников
     на карту, в кадре обычно 4–11.
  3. HUD/вигнетка/debug обязаны быть ВЫШЕ маски: слои — мир 0..3 → тьма 14 →
     мошь 16 → вигнетка 18 → HUD 22 → debug 24 → мини-карта 30.
  4. Вигнетка под маской бесполезна (тьма её съедает) — только над ней.
  5. `erase` на RenderTexture — это draw с blend ERASE: у Image должна быть
     alpha 1, иначе дыра будет «недовырезана».

## 2026-10-27 · Шаг 6: боёвка, голод и поедание

- **Решение:** боевая петля собрана из семи систем: `HitStop` (полная заморозка
  симуляции: physics.pause + tweens.pauseAll + emitter.timeScale=0, тряска камеры
  и числа урона живут — классический «мир замирает на кадр»), `Combat` (укус:
  ready → windup 110 мс с телеграфом-сжатием → active 130 мс с рывком и хитбоксом
  сектора → recover 420 мс; кнопка контекстная — рядом туша значит «есть»),
  `BloodFx` (кровь трёх слоёв по гайду §7: брызги-частицы с гравитацией; «липкие»
  декали — в момент смерти частицы сетка пещеры подсказывает стену/пол, декаль
  темнеет 6 с и уходит 30 с из пула на 220; съедобные сгустки; числа урона),
  `Enemy` (FSM-скелет wander → flee → windup → lunge → stunned → dead; силуэт
  вне света — двойник-спрайт над маской, как мошь шага 5), `Eating` (туша = мясо
  в очках голода: чавканье по 10 за 190 мс, куски летят изо рта, туша тает
  визуально и истлевает за 40 с), `Vitals` (голод −1.4/2 с, при нуле HP тает
  3/1.5 с; опыт → уровни: +10 HP, +2 укус, +8 голод, аппетит +4%, масштаб
  +3.5%, максимум ур. 8), `Mutations` (шанс 25%, взвешенный пул 8 геномов без
  повторов, хуки эффектов в существующие системы: сцепление/двойной прыжок —
  в Creature.mods, стан/шипы — в Combat, маскировка — в детекции мобов).
  Добыча шага 6 — слизень и нетопырь у гнёзд шага 4 + 2 гарантированных слизня
  у входа («много мелкой еды, безопасный старт»). Все числа — `balance.json`,
  виды — `enemies.json`, геномы — `mutations.json`.
- **Почему так, а не дешевле:** хитстоп «паузой сцены» сломал бы тряску и числа;
  декали одним RenderTexture нельзя ни потемнеть, ни уйти по сроку — пул спрайтов
  с твин-жизнью даёт точную логику гайда и батчится в один draw call; контратака
  добычи даёт игроку урон уже сейчас (HP не пустая) и учит читать телеграфы
  (замах 340 мс — по гайду «0,3–0,4 с с подстветкой») до того, как шаг 7 навалит
  6 видов сразу. Сетчатая «липкость» крови — детерминированная и бесплатная
  альтернатива физике частиц.
- **Нейрогенерация (разрешена с шага 5+):** splash-арт меню сгенерирован
  Nano Banana Pro (ai.gptml.ru) по промпту в палитре проекта; один «одинокий»
  образ — то, в чём нейрогенерация сильна (гайд §5). Файл — `assets/menu-splash.jpg`
  (1280×720, 133 КБ), в билде детерминирован.
- **Отвергли:** физику для частиц крови (дорого и недетерминированно),
  RT-слой декалей (нельзя темнеть/уходить по срокам), урон при касании моба
  (читаемость: только телеграфированный выпад), aim-укус мышью (фантомная
  точность против ИИ шага 7; взгляд = направление бега).
- **Грабли:**
  1. `camera.shake(duration, intensity)` в Phaser — intensity это ДОЛЯ ширины
     кадра, не пиксели: 4 px = `4 / cam.width`. Проверено по исходникам.
  2. «Прижатая добыча» не ловится проверкой `blocked.left/right` в момент
     триггера: панические прыжки держат моба в воздухе, blocked сбрасывается.
     Решение — накопитель «безуспешного давления в стену» (stuckMs 450).
  3. Укус-выпад моба на низком fps проходит между кадрами — точечная проверка
     никогда не совпадает с окном 220 мс. Решение — свип-проверка коридора
     выпада (from→to, ±26 px) на истечении окна: выпад — это размах.
  4. Опыт туши нельзя считать от остатка (`xpLeft -= share`) — опыт «съедает
     сам себя» (24 → 16.9). Считать от полной ценности вида.
  5. Потолок мутаций надо проверять и на выпадении (owned + невыбранные
     кристаллы ≤ maxOwned), и при подборе — иначе 30 бросков подряд набьют
     10 кристаллов в 6 слотов.
  6. CDP-`keydown` в agent-browser несёт keyCode 0 — Phaser (читает keyCode)
     клавишу не видит; `press` работает иначе. Для автотестов клавиатуры —
     синтетические KeyboardEvent с явным keyCode (Phaser не проверяет isTrusted)
     либо хуки `__CAVE__`.
  7. Death-рестарт: `kb.removeAllListeners()` не нужен — всё и так умирает со
     сценой; ручная зачистка рискует снести служебные подписки плагина.

## Шаг 7 — Мобы и живая экосистема

**Дата:** сессия шага 7. **Коммит:** step7.

- **FSM как у гайда, но шире:** патруль → тревога → погоня → замах → атака →
  отход + бегство при HP<25%. «Тревога» (alert) — из слуха: чужой удар/замах
  рядом будит патрульных, они идут смотреть. Решения — на «тиках мышления»
  190–320 мс с рандомной фазой: пещера не думает хором, поведение неровное,
  живое, и это же дёшево по CPU (18–22 моба × O(n) — мелочь).
- **Экосистема по гайду:** мобы дерутся между собой, только когда игрок дальше
  `peaceRadius` (420 px) — «дерутся, когда игрока нет рядом». Добыча и стычки
  создают туши, падальщики едят их и растут сами — экосистема соревнуется
  с игроком за еду. Мутации и счётчик «съедено» — только за игроком.
- **Отношения — данные, не код:** `hunts`/`fears` в enemies.json + таблица
  `byBiome` по полосам шага 4. Новый вид = запись в JSON + спрайт.
- **Панцирь и кислота:** броня — сопротивления по типам урона в JSON.
  Мутация «Кислотные железы» (шаг 6) теперь делает укус КИСЛОТНЫМ — её
  описание уже обещало «пробивает панцири» (связка шагов без новых сущностей).
- **Свёртка панциря:** вместо бегства (тяжёлому не убежать) — неуязвимость
  и лечение. Грабли: см. ниже.
- **Каналы урона:** пиявка и огонь НЕ расходуют неуязвимость после удара
  (это не удар, а среда), но уважают смерть/«Второе сердце». Спора — снаряд,
  поэтому как удар (с неуязвимостью) + замедление существа (BALANCE.spore).
- **Шум в темноте:** кольца над маской тьмы (пул 18) в цвете вида — писк,
  замах, удар, еда. «Стоишь и слушаешь» работает глазами до звука (шаг 10).
  На низком качестве кольца не рисуются, но слух (alert) работает.
- **Грабли:**
  1. Свёртка перезапускалась сама: think-тик (≈250 мс) снова входил в curl
     и сбрасывал таймер лечения (healPerSec не срабатывал никогда). Решение —
     curl в списке состояний, где think молчит; лечение доигрывает цикл.
  2. Споровые болты вплотную жгут самого жнеца (болт спавнится у дула и
     лопается на радиусе 12 px) — дружественный огонь честный, но в бою жнец
     стреляет от 92 px, а хук теста стрелял вплотную. Не баг — фича экосистемы.
  3. FireTrail-свет: дыры маски надо УБИРАТЬ при гашении лужи — добавлен
     `DarknessMask.remove()`; иначе лужи накапливают дыры навсегда.
  4. Песочница пересоздалась между реализацией и коммитом — несохранённый
     шаг 7 пропал целиком и был переприменён из журнала. Урок: коммит сразу
     после зелёного typecheck, до долгой верификации в браузере.

## Шаг 8 — Геномы: забеговые мутации и постоянные гены

**Дата:** сессия шага 8. **Коммит:** step8.

- **20 мутаций по таблице гайда (глава 6)**: 4 обычных, 4 необычных, 5 редких,
  3 эпических, 2 легендарных, 2 проклятия. Легендарные исключены из общего
  пула (weight 0) — только с уникальных мобов. Проклятия выпадают редко
  (weight 6 против 14–40) и «нельзя выбросить» — стыкуются с шагом 11
  (стабилизация веткой «Гены»).
- **Редкости чувствуются**: цвет кристалла/баннера/рамки слота по редкости;
  легендарка — золото мяса, проклятие — глубокий багровый.
- **Постоянные гены — это JSON + localStorage** (cave-genes-v1): genes[] +
  stats{runs, deaths, bestDepthM, bestEaten}. Применяются к СТАРТУ каждого
  забега поверх забеговых мутаций; меню показывает собранное.
- **Источники по гайду**: мутагенные цветки (6 на карту, детерминированно от
  seed) → бросок забеговой мутации; ген-лунки (2 на карту, только глубина
  ниже 55% карты) → постоянный ген; уникальные мобы (элита ×3 HP, споровая
  аура, максимум 2 на карту у гнёзд биомов ≥2) → золотой геном-кристалл.
- **Связки без новых сущностей**: «Кислотные железы» уже обещали пробой
  панциря (шаг 7); «Корона Матки» переиспользует облик слизня с фиолетовой
  краской — спутник следует за маткой и кусает ближайшую добычу.
- **Смерть возвращает в меню** (гайд шаг 8): экран итога — рацион по видам
  (Eating.eatenBySpecies), причина смерти (Vitals.lastDamageCause ставится
  в каждом канале урона), постоянные гены забега; статистика копится в сейве.
- **Грабли:**
  1. Множитель света игрока был СТАТИКОЙ в дыре маски (radius считан при
     create) — «Светожорное ядро» не гасило свет. Решение: LightSource
     .radiusMult — функция, читается каждый кадр (246 → 111 проверено).
  2. Мультипликативные эффекты (stealth × проклятие маскировки) нельзя
     присваивать (=) — только умножать (*=), иначе перезапись.
  3. Хук верификации элит не отдавал y — телепорт в NaN и ложный «не убивается».
     Всегда отдавай полные координаты из тест-хуков.

## Шаг 9 — VFX-полиш: сок из игры

**Дата:** сессия шага 9. **Коммит:** step9.

- **Хроматическая аберрация — свой GLSL-пайплайн.** В Phaser 3.90 встроенной
  нет: PostFXPipeline с фрагментным шейдером, RGB-каналы расходятся от центра
  на uOffset. Пайплайн ставится на камеру ТОЛЬКО на время эффекта (set/remove
  на лету) — постоянного оверхеда нет. Триггеры: урон ≥12 или HP<50%,
  смерть уникального (×1.5).
- **Slow-mo 0.3 с уникальных убийств**: physics.world.timeScale = 4 + tweens
  timeScale 0.25 + эмиттеры 0.25 (HitStop.slowMo) + zoomTo 1.035 и обратно.
  Хитстоп (freeze) сильнее slow-mo — конфликтов нет: разморозка уважает
  замедление и наоборот.
- **Glow-реестр**: пост-эффект на спрайтах света (грибы, врата, аура элиты).
  Регистрируешь — применяешь; Q переключает на лету (QUALITY.onChange).
  На Canvas-рендерере эффекты молча пропускаются (груaceful-деградация).
- **Вспышки поедания**: пул из 6 бликов (не GC) у пасти на каждом чавканье,
  крупный всплеск + слабый flash камеры на доедании туши.
- **Искры**: общий пул BloodFx с текстурой spark (6×6): «кланк» панциря,
  золотой бёрст ×18 на уникальных.
- **Грабли:**
  1. `postFX.addGlow({ intensity ... })` — несуществующая сигнатура: реально
     `addGlow(color, outerStrength, innerStrength, knockout?, quality?, distance?)`.
  2. Кастомный пайплайн камеры регистрируется через
     `renderer.pipelines.addPostPipeline(key, Class)`, а контрол через
     `cam.getPostPipeline(key) as ChromaticPipeline` — типизация Phaser
     возвращает Controller, приводим к своему классу.
  3. Пайплайн камеры с offset=0 всё равно стоит проход — поэтому ставим
     только на 420 мс эффекта и снимаем.

## Шаг 10 — звук, музыка и производительность

**Дата:** сессия шага 10. **Коммиты:** step10 (perf), step10 (audio), step10 (docs).

- **Маска тьмы — один GLSL-проход.** Было: RenderTexture — каждый кадр
  `fill` (полный экран) + `erase` на КАЖДЫЙ источник (тоже полный экран):
  20+ полноэкранных композитов за кадр. Стало: GameObject Shader с
  фрагментным шейдером: до 32 источников uniform-массивом `3fv`, форма дыры
  повторяет light-hole.png (плато до 45%, линейный спад), света
  перемножаются «прозрачностью» — как при erase. Canvas-фолбэк — прежний
  RT, но дыры батчатся (beginDraw/batchDraw/endDraw).
- **Glow: postFX → bloom-спрайты.** Каждый объект с postFX в Phaser 3.60+
  рендерится в ОТДЕЛЬНЫЙ фреймбуфер (2+ пасса): 14 грибов + врата + ауры
  элит = десятки пассов за кадр — главный источник просадки. Bloom — копия
  ореола ×1.9 масштаба, альфа ×0.35, синхронизируется с целью в Vfx.update:
  три десятка присваиваний, ноль пассов.
- **Пул эмиттеров**: раньше каждый бёрст крови создавал ParticleEmitter и
  отложенно уничтожал его (GC-паузы в бою). Теперь эмиттеры живут вечно по
  ключу «текстура:липкость», на бёрст — setConfig + emitParticleAt.
- **HUD только по изменениям**: Graphics перерисовывается, когда меняется
  хоть одно видимое значение (квант 1/200 полосы); рамки слотов —
  статичный Graphics; тексты кэшируются по строке. DebugOverlay выключен
  по умолчанию (F3, выбор в localStorage) — setText перерисовывает
  канву-текстуру каждый кадр.
- **FPS-guard**: если реальный FPS < 40 три выборки подряд (после 9 c
  прогрева) — качество автоматически падает до «низкого», тихий тост
  объясняет. Однократно за сессию; Q возвращает «высокое» вручную.
- **Звук — весь синтезирован в браузере** (jsfxr-подход гайда, ноль
  аудиофайлов): пресеты из audio.json → Float32 PCM (systems/sfxr.ts:
  огибающая атака→спад, слайд частоты, вибрато, шумовая подмесь,
  однополюсный lowpass, повторы огибающей для сердцебиения) →
  AudioBuffer через `ctx.createBuffer` + `getChannelData(0).set` —
  СИНХРОННО, минуя decodeAudioData. Музыкальные петли — процедурные
  генераторы: гул (кластер синусов с LFO-дыханием + шумовое ложе), капли
  (пинги со спадом и эхом), бой (бочка + диссонансные схватки + шляпы,
  132 BPM), глубина (пэд-кластер с тремоло + редкий колокол). LFO-периоды
  кратны длине петли — бесшовность.
- **Кроссфейды без твинов**: в кадре громкость слоя едет к цели линейно
  (fadeUp 900 мс / fadeDown 1600 мс — бой не мигает), гистерезис боя
  1100 мс после последней угрозы. Слои создаются лениво (первая драка).
- **Громкости**: music/sfx 0..1, ползунки-сегменты ×10 в меню, клик по
  строке ставит долю, звук-подтверждение играет с новой громкостью,
  localStorage `cave-audio-v1`. Клик по зоне ползунков НЕ уводит в пещеру
  (единый обработчик с фильтром зоны).
- **Грабли (дорогие):**
  1. Числовые листья конфига — ТОЛЬКО плоские числа. `sampleRate: {_doc, value}`
     дал NaN в длине буфера → `createBuffer` падал «non-finite», а WAV-декод
     зависал навсегда (промисы не разрешались). Мелкие данные маскировали
     баг: `Float32Array(NaN)` — пустой валидный массив.
  2. `decodeAudioData`, выданный в момент загрузки страницы, в части
     окружений зависает молча — отказались в пользу прямого createBuffer
     (быстрее и синхронно).
  3. `.replace('MAX_LIGHTS', ...)` меняет только ПЕРВОЕ вхождение — шейдер
     с константой в двух местах не компилился и ронял сцену. Глобальный
     regex обязателен.
  4. `_doc`-поля попадают в `Object.entries(config.sfx)` — при итерации
     пресетов пропускать ключи с `_`-префиксом.
  5. Headless-браузер агента троттлит rAF до ~1 Гц — мерить не FPS, а
     CPU-стоимость кадра (синхронный `loop.step()`): она не врёт.

## Шаг 11 — фикс «зависания намертво» после поедания трупа

**Симптом:** первая же трапеза тушей замораживала игру без ошибок на экране: rAF-цепочка
Phaser умирала навсегда (ватчдог `__RAF__` тикал, `Vitals.update` — нет).

**Корень:** шаг 10 перевёл `vfx.json` на формат `{ключ: {_doc, value}}`, но доступ остался
слепым кастом `data as unknown as VfxConfig`. Все поля превратились в объекты:
`0 < {объект}` — всегда false → пул вспышек никогда не заполнялся → `undefined.setPosition`
в `Vfx.eatFlash` на первом же чавканье → исключение внутри шага сцены → следующий rAF
не планировался → игра «намертво». Те же NaN лежали в `slowMoMs` (слоу-мо не кончался
никогда) и всех блум-параметрах.

**Решение (дорогое, системное):**
1. `src/config/unwrap.ts` — разворачиватель `{_doc, value}`-конфигов с валидацией:
   `assertNumbers` роняет СТАРТ с понятной ошибкой, если лист не конечное число.
2. `vfx.ts` — unwrapDoc + assertNumbers по всем 11 полям (ошибка конфига невозможна молча).
3. Страховка цикла: `CaveScene.update` обёрнут в try/catch — ошибка одного кадра
   логируется в `__ERRS__` (первые 8), мир продолжает жить. Хитстоп-разморозка — вне
   страховки: мир обязан ожить даже после ошибочного кадра.

**Грабли:** ватчдог должен снимать СТЕК (`e.error.stack`), «message @ file:line» в
минифицированном бандле не указывает на источник. И: правки сцен скриптом по номерам
строк — дважды проверяй границы (первая попытка съела `hitStop.update()`).
