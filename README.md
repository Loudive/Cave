# 🕳️ Cave Devourer — Пожиратель пещер

**2D-платформер-роуглайк в тёмном фэнтези, где игрок управляет не героем, а монстром.**

Ты — одно из существ гигантской сети тёмных пещер. Чтобы расти, нужно охотиться
и пожирать другую фауну. Мир почти лишён дневного света: всё освещение —
биолюминесценция грибов, лишайников и самих существ. Свет — ресурс и угроза
одновременно: чем ярче светишься, тем больше видишь, но и тем заметнее для
охотников. В глубине прячутся уникальные монстры и редкие геномы, ради которых
стоит рисковать.

**Ключевая фишка** — разнообразие способов передвижения: парение на споровом
зонте, ползание по стенам и потолку кровавыми сгустками, тросы-щупальца.
Это целые ветки билдов: часть пещер физически невозможно пройти «не тем» существом.

## Запуск локально

```bash
npm install

```

Сборка и проверка прод-билда:

```bash
npm run build      # typecheck + vite build → dist/
npm run preview
```

## Деплой

Каждый пуш в `main` автоматически собирает билд и публикует его на
**https://loudive.github.io/Cave/** (GitHub Actions, workflow `deploy.yml`).

## Управление (шаг 5, свет и атмосфера)

`A/D` (стрелки) — бег · `SPACE` — прыжок · `W` (вверх, в воздухе) — планирование ·
у стены в падении — wall slide, `SPACE` — wall jump · `R` — та же пещера заново ·
`N` — новая пещера · `M` — мини-карта · `ESC` — меню · `F3` — debug-оверлей.

- **Свет = ресурс и риск (GDD §7)**: пещера во тьме; свет существа (радиус из
  `light.json`, «дышит») — единственное, что видно вокруг. Грибы светятся в цвет
  биома и мерцают, гнёзда зловеще подсвечены, врата «▼ глубже» — цианный маяк
  пути. Вне света — силуэты: мошь тьмы растворяется в свете (механика мобов из
  шага 7). Вигнетка-тоннель и два параллакс-слоя силуэтов пещеры.
- **Seed в URL**: `?seed=Q5TUN6&d=2` — та же пещера воспроизводится и шарится ссылкой.
- **Слои глубины**: у выхода «▼ глубже» — следующий слой того же забега (d+1).
- **Биомы по глубине** (GDD §6): Грибные поляны → Кровавые жилы → Кислотные гроты →
  Лавовые глубины → Затопленные туннели → Забытые храмы; границы полос дрожат шумом.
- Все параметры генерации — в `src/config/gen.json`, движения — в `src/config/movement.json`,
  света — в `src/config/light.json`.
