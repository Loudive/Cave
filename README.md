# 🕳️ Cave Devourer — Пожиратель пещер

**2D-платформер-роуглайк в тёмном фэнтези, где игрок управляет не героем, а монстром.**

Ты — одно из существ гигантской сети тёмных пещер. Чтобы расти, нужно охотиться
и пожирать другую фауну. Мир почти лишён дневного света: всё освещение —
биолюминесценция грибов, лишайников и самих существ. Свет — ресурс и угроза
одновременно: чем ярче светишься, тем больше видишь, но и тем заметнее для
охотников. В глубине прячутся уникальные монстры и редкие геномы, ради которых
стоит рисковать.

**Ключевая фишка** — разнообразие способов передвижения: парение на споровом
зонте, ползание по стенам и потолку кровавыми сгустками, тросы-щупальца.
Это целые ветки билдов: часть пещер физически невозможно пройти «не тем» существом.

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка и проверка прод-билда:

```bash
npm run build      # typecheck + vite build → dist/
npm run preview
```

## Деплой

Каждый пуш в `main` автоматически собирает билд и публикует его на
**https://loudive.github.io/Cave/** (GitHub Actions, workflow `deploy.yml`).

## Управление (шаг 12, боёвка, карабканье, голод и поедание)

`A/D` (стрелки) — бег · `SPACE` — прыжок · `W` (вверх, в воздухе) — планирование ·
**карабканье (шаг 12): с прыжка коснись стены — монстр цепляется когтями,
`W`/`S` — ползти по стене вверх/вниз, `SPACE` — прыжок от стены, тянуть от
стены — отцепиться** · `J` / ЛКМ / тач-кнопка — укус (рядом туша — съесть) ·
`R` — та же пещера заново · `N` — новая пещера ·
`M` — мини-карта · `Q` — качество (частицы/декали) · `ESC` — меню · `F3` — debug.

- **Свет = ресурс и риск (GDD §7)**: пещера во тьме; свет существа (радиус из
  `light.json`, «дышит») — единственное, что видно вокруг. Грибы светятся в цвет
  биома и мерцают, гнёзда зловеще подсвечены, врата «▼ глубже» — цианный маяк
  пути. Вне света — силуэты: мошь тьмы растворяется в свете (механика мобов из
  шага 7). Вигнетка-тоннель и два параллакс-слоя силуэтов пещеры.
- **Seed в URL**: `?seed=Q5TUN6&d=2` — та же пещера воспроизводится и шарится ссылкой.
- **Слои глубины**: у выхода «▼ глубже» — следующий слой того же забега (d+1).
- **Биомы по глубине** (GDD §6): Грибные поляны → Кровавые жилы → Кислотные гроты →
  Лавовые глубины → Затопленные туннели → Забытые храмы; границы полос дрожат шумом.
- **Ядро фантазии (GDD §1): укус, кровь, чавканье.** Укус с телеграфом замаха
  (сжатие существа → рывок с хитбоксом), хитстоп 80 мс и тряска 4 px при попадании,
  кровь в три слоя: брызги с гравитацией и «липкостью» к стенам, декали, которые
  темнеют и уходят за 30 с, съедобные сгустки на месте смерти.
- **Туша = еда и рост**: чавканье по кускам возвращает голод, чуть HP и опыт
  роста; существо visibly растёт с уровнем (масштаб, HP, укус, аппетит).
  Шанс 25% — из туши вырастает кристалл мутации (8 геномов из GDD §6: сцепление,
  двойной прыжок, электроорганы, второе сердце…). Голод тикает каждые 2 с;
  при нуле HP тает — пещера выгоняет охотиться.
- **Живая экосистема (шаг 7)**: шесть видов с полным FSM — патруль → тревога →
  погоня → замах → атака → отход; бегство при HP<25% (панцирь вместо этого
  свёртывается). **Без тебя пещера живёт своей жизнью**: мобы охотятся друг на
  друга (кровосос пьёт HP у слизней и нетопырей, лавовый ползун жжёт всех),
  падальщики доедают туши (и твою добычу — успей первым!), гнёзда возрождают
  население. Шум пещеры виден сквозь тьму — кольца писка и драк.
- **Шесть видов**: мышевидный слизень (быстрый, слабый, кусается в углу),
  пещерный нетопырь (синус-полёт, ныряет на раненых), споровый жнец
  (территориальный стрелок — веер спор, держит дистанцию), кровосос
  (пиявка: присасывается и пьёт HP, лечась), бронепанцирь (физический урон
  почти не берёт — нужна мутация «Кислотные железы»), лавовый ползун
  (оставляет за собой горящие лужи со светом в темноте).
- **Геномы (шаг 8)**: 20 забеговых мутаций шести редкостей по таблице гайда —
  включая легендарные («Светожорное ядро»: свет гаснет, урон ×3; «Корона
  Матки»: побеждённый мелкий моб становится спутником) и проклятия
  («Голодные жил», «Прозрачная кожа» — сильные, с минусом, не выбрасываются).
  6 слотов в HUD. Мутагенные цветки на полах дают дополнительные броски.
- **Постоянные гены**: переживают смерть, живут в localStorage. Источники —
  только уникальные мобы (элитные, ×3 HP, споровая аура) и ген-лунки в
  глубоких биомах: 7 стат-генов и «Геном-гнездо» (+1 слот навсегда).
- **Смерть — итог забега**: что съел (по видам), рост, мутации, глубина,
  на чём погиб → возврат в Гнездо; накопительная статистика (забеги,
  смерти, рекорды) сохраняется.
- **Звук и музыка (шаг 10)**: все SFX синтезируются в браузере по пресетам
  (jsfxr-подход): укус, чавканье, глоток, боль, смерть моба, рык уникального,
  сердцебиение, кланк панциря, подборы, интерфейс. Эмбиент — гул пещеры и
  капли; музыка — процедурные петли: слой боя (кроссфейд в драке с
  гистерезисом) и слой глубины (кроссфейд глубже 600 м). Громкости
  «Музыка / Эффекты» — ползунки в меню, хранятся в localStorage.
- **Производительность (шаг 10)**: маска тьмы — один GLSL-проход (было
  RT fill + до 20 erase за кадр), ореолы — дешёвые bloom-спрайты (было
  postFX на каждом объекте — отдельные фреймбуферы), пул частиц, HUD
  перерисовывается только при изменениях, FPS-guard сам включает низкое
  качество при FPS < 40. Кадр — единицы мс даже на программном рендере.
- Все параметры генерации — в `src/config/gen.json`, движения — в `src/config/movement.json`,
  света — в `src/config/light.json`, боя/еды/роста — в `src/config/balance.json`,
  добычи — в `src/config/enemies.json`, мутаций — в `src/config/mutations.json`,
  звука — в `src/config/audio.json`.
